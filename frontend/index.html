Archival Format Reference — How TVF-1 Preserves Exact Tree Shape
  • Header (TVF-1): Identifies the TreeVault archival specification version.
  • Declared Count (COUNT:<n>): Records the exact number of non-null nodes (0 to 2,000) for integrity checking.
  • Serialized Stream (DATA:...): Iterative preorder sequence of comma-separated tokens.
  • N:<label>: Represents an actual node (1–16 chars: letters, digits, _, -).
  • X: Represents an explicit missing (null) child position. Retaining null markers eliminates structural ambiguity—even when labels repeat or a node has only a left or right child.
